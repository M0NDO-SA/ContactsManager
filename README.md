# ContactsManager

## 📌 Description

ContactsManager est un petit projet Java basé sur la Programmation Orientée Objet (POO).

Le programme permet de :
- créer des contacts,
- ajouter des contacts dans une liste,
- rechercher un contact par son nom,
- afficher son numéro de téléphone.

---

## 🧠 Concepts utilisés

Ce projet utilise les notions vues en cours :

- Classes et objets
- Attributs et méthodes
- Constructeur
- Tableaux d’objets
- Boucles
- Conditions
- Méthode main

---

## 📁 Structure du projet

Le projet contient 3 fichiers Java :

- Main.java → point d’entrée du programme
- Contact.java → classe représentant un contact
- ContactsManager.java → gestion des contacts

---

## ⚙️ Fonctionnement

1. Le programme crée un gestionnaire de contacts.
2. Plusieurs contacts sont créés avec un nom et un numéro.
3. Les contacts sont ajoutés dans une liste.
4. Le programme recherche un contact par son nom.
5. Il affiche le numéro du contact trouvé.

---

## 🧪 Exemple d’utilisation

Le programme recherche un contact nommé "Awa" et affiche son numéro de téléphone.
